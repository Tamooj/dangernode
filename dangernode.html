Global Settings
Applies to every wire, plus Quick Check, the Counterpoise Reference and Suggest Lengths panels. Bare wire is commonly ~0.95; insulated/jacketed wire can run lower. Wire length stays per-wire — see the Calculator tab.
How close to a half-wave multiple (integer n, where the feedpoint is high-Z) counts as "danger." The farthest any length can be from one is 0.5. Amber (marginal) buffer is 2x this value. Applies everywhere — chart shading, band verdicts, Quick Check.

Band Verdicts
Counterpoise Reference (informational only)
Free-space quarter-wave rule of thumb (246 / f_MHz), VF-adjustable via the global VF (Settings tab). Not part of the danger-zone calculation — no ground/counterpoise coupling is modeled.
Suggest Lengths — land a band on a high-current point
Lengths that put the reference frequency exactly midway between half-wave multiples (n = ½, 1½, 2½…), as far from the high-Z points as a length can get, using the global VF (Settings tab). "Apply" loads the length into wire 1. The summary shows the tradeoff against your other shown bands.
