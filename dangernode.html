Global Settings
Applies to every wire in both tabs, plus the Counterpoise Reference and Suggest Lengths panels. Bare wire is commonly ~0.95; insulated/jacketed wire can run lower. Wire length stays per-wire — see the EFHW / Random Wire tabs.
How close to an even-integer node counts as "danger." Amber (marginal) buffer is 2x this value. Applies everywhere — chart shading, band verdicts, Quick Check.
Shortcut buttons that set the tolerance slider above to a rough starting point for your matching setup. These are estimates, not measured values — no radio will be selected if the slider has been moved to a value that doesn't match one exactly.

Band Verdicts
Counterpoise Reference (informational only)
Free-space quarter-wave rule of thumb (246 / f_MHz), VF-adjustable via the global VF (Settings tab). Not part of the danger-zone calculation — no ground/counterpoise coupling is modeled.
Suggest Lengths — land a band on an antinode
Lengths that land the reference frequency exactly on a voltage-antinode (odd n), using the global VF (Settings tab). "Apply" loads the length into wire 1. Other verdict columns show the tradeoff against your other shown bands.
